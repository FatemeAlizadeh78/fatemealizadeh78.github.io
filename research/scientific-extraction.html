From scientific sentences to structured knowledge

A sentence-to-JSON study of scientific entities and directed relations, comparing prompting, parameter-efficient adaptation, and a split-task Gemma–SciBERT pipeline.

Natural language processing2026Explore the source code ↗

The question

Can separating entity generation from relation classification improve scientific information extraction compared with direct JSON generation?

Experimental design

  • Converted SciER into sentence-level entity/relation JSON: 5,575 training, 713 development, 854 test, and 580 out-of-domain examples.
  • Compared FLAN-T5 baselines, Qwen2.5-1.5B-Instruct, Llama-3.2-1B-Instruct, and Gemma-2-2B-it with zero-shot/few-shot prompting and LoRA adaptation.
  • Fine-tuned Qwen and Llama on 3,000 examples each and Gemma on 5,000; model and data budgets therefore differ.
  • Used Gemma LoRA to generate entity candidates, then typed directed pairs and SciBERT to classify relations. Evaluated entity spans/types, directed triples, JSON validity, and out-of-domain behavior.

These are recorded course-experiment results. The split-task relation threshold was selected on the normal test set, so that row is not an untouched held-out benchmark. The OOD run reused the selected threshold. Qwen’s 854 saved predictions were independently re-scored and matched the recorded metrics; no new GPU inference is claimed.

What the experiment does not establish

  • The exported artifacts lack the trained final SciBERT classifier; an exact full-pipeline replay requires that checkpoint or a new training run.
  • Reported comparisons use unequal fine-tuning budgets. They do not establish statistical superiority.
  • The task is sentence-level extraction. Autonomous agents, arbitrary PDF parsing, and RAG systems were not implemented; structured scientific knowledge is relevant to those future applications.

Reproduce and inspect

Install the CPU package, run the synthetic rule baseline, evaluate its JSONL outputs, and inspect the saved metric tables. Optional GPU training and inference are documented separately.
